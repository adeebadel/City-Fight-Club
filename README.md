# City Fight Club Website

Premium, responsive React + Vite website for City Fight Club, Bengaluru.

## Start
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Edit content in `src/config/siteConfig.js` and image paths in `src/config/images.js`. Read `EDITING_GUIDE.md` before updating the site.

**Before publishing:** replace all placeholder details, verify branch schedules/pricing/contact links, and add approved real academy photographs.
